# Public Vault Access System

## Executive Summary

FUZE uses the **Public Vault Access System** to make selected vault-token access visible, eligibility-controlled, market-aligned, lockup-aware, and compliance-gated.

The system supports FUZE’s Controlled Circulation Policy by avoiding hidden unlock pressure and reducing the need for automatic token releases into private wallets. When selected vault tokens become available under approved policy, they appear through transparent access windows on FUZE public surfaces. Eligible participants access those tokens through defined rules, market-aligned pricing, purchase limits, lockups, eligibility controls, smart contract references, and compliance boundaries.

The Public Vault Access System strengthens holder, investor, and community confidence by showing the source vault, purpose, pricing method, access rules, proceeds destination, policy reference, contract reference, transaction history, and risk boundary for each selected access window.

FUZE does not describe this system as unrestricted public buying. FUZE describes it as **publicly visible, eligibility-controlled access**.

This paper defines the public model for Public Vault Access, how it connects to controlled circulation, which vaults can be relevant, how eligibility and market-aligned pricing work, how proceeds are handled, what reporting is expected, and which risk boundaries apply.

## 1. FUZE Position

FUZE presents the Public Vault Access System as a transparency and controlled-circulation mechanism.

FUZE position:

**Public Vault Access is a publicly visible, eligibility-controlled, market-aligned, lockup-aware, and compliance-gated system for selected vault-token access where final policy allows.**

The Public Vault Access System follows FUZE’s core tokenomics principle:

**Purpose-specific allocation. Vault-based control. Controlled circulation. Product-first utility. Long-term ecosystem alignment.**

Public Vault Access exists to make selected token access more transparent and policy-based. It is not a hidden distribution channel, not unrestricted public buying, not a listing substitute, not a liquidity assurance system, and not a financial-return plan.

FUZE uses Public Vault Access only where product, legal, compliance, jurisdiction, platform, technical, smart contract, treasury, and policy readiness support it.

## 3. Public Model

Public Vault Access is a controlled access system for selected vault tokens.

| Element | Public Meaning |
|---|---|

| Purchase / access limits | Maximum or minimum access amounts where policy requires |
| Lockup | Holding or release restriction designed to support controlled circulation |
| Compliance gate | Legal, jurisdiction, eligibility, and policy controls where applicable |
| Contract reference | Public contract, vault, or transaction reference where available |
| Policy reference | Public policy hash, document reference, or governance record where available |
| Proceeds destination | Public explanation of where proceeds go where applicable |

Public Vault Access gives readers a clearer view of why tokens move, where they come from, and what rules apply.
